# Data Analysis Projects Portfolio with Power BI Dashboards

Welcome to a comprehensive collection of **data analysis projects featuring Power BI dashboards**. This portfolio demonstrates practical applications of data analysis, business intelligence, and data visualization across various industries and domains. These projects are designed to help aspiring data analysts kickstart their careers and understand real-world data analysis workflows.

This repository contains **13 diverse data analysis projects** spanning multiple industries including retail, finance, automotive, food & beverage, technology, and more. Each project includes raw data, analysis, and interactive Power BI dashboards.

### 2. **Banking Fraudulent Transactions Data Analysis**
**Domain:** Finance & Banking | **Tools:** SQL, Power BI, Data Analysis  
**Description:** This comprehensive project analyzes fraudulent transaction patterns in banking data using SQL and Power BI dashboards. The analysis focuses on helping banking stakeholders understand customer behavior and identify fraudulent transactions. The dataset was sourced from Kaggle. Key insights extracted include:
- Overall transaction performance and trends over time
- Fraud percentage and patterns in transactions
- Geographic analysis of fraud incidents by city
- Transaction type analysis and fraud propensity
- Card type fraud correlation
- Expense type distribution and patterns
- Customer behavior analysis and transaction patterns
- Gender-based transaction behavior and fraud trends

**Files:**
- Banking_Fraudulent_transactions-DataAnalysis.ipynb (Jupyter Notebook)
- SQL queries and analysis scripts
- Interactive Power BI dashboard

**Use Case:** Banking stakeholders can leverage these insights to enhance fraud prevention strategies and improve overall business processes.
